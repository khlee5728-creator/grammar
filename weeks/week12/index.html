Week 12

-ing and to... (Part 1)

동명사와 부정사 (1)

Units 51 – 56

Learning Objectives

이번 주 학습 목표

  • Know which verbs are followed by -ing (gerund) 동명사(-ing)가 따라오는 동사를 알 수 있다
  • Know which verbs are followed by to + infinitive to부정사가 따라오는 동사를 알 수 있다
  • Understand verbs that change meaning with -ing vs. to... -ing와 to...에 따라 의미가 달라지는 동사를 이해할 수 있다
  • Avoid common Korean-speaker errors with gerunds and infinitives 동명사와 부정사에서 한국어 화자의 흔한 실수를 피할 수 있다

Verb + -ing (enjoy doing / stop doing, etc.) Unit 51A

동명사(-ing)가 뒤따르는 동사 + 부정형 (not + -ing)

A After enjoy / mind / suggest + others, use -ing (not "to ...")

📖 "After enjoy, mind, and suggest, we use -ing (not to ...)." (Unit 51A)

enjoy, mind, suggest, stop, finish, recommend, consider, deny, avoid, risk, miss, imagine
"I enjoy reading." (NOT "enjoy to read")
"Would you mind closing the door?"
"Chris suggested going to the movies."
"They denied doing anything wrong."

▸ Negative form — not + -ing

"When I'm on vacation, I enjoy not having to get up early."

📖 GIU Unit 51A, p.102

Verb + -ing — phrasal verb expressions Unit 51B

구동사 + -ing: give up / put off / go on / keep (on)

B After give up / put off / go on / keep (on), use -ing

give up doing = stop, stop trying
put off doing = delay until later
go on doing = continue
keep / keep on doing = continuously / repeatedly
"I gave up talking to them; they don't listen."
"You shouldn't put off telling him what happened."
"Katherine doesn't want to retire. She wants to go on working."
"You keep interrupting me when I'm talking."

📖 GIU Unit 51B, p.102

Verb + somebody + -ing Unit 51C

동사 + 사람(목적어) + -ing — -ing의 주체가 동사 주어와 다를 때

C verb + somebody + -ing

With some verbs (imagine, remember, keep, hear, see, feel, find, catch), you can use the structure verb + somebody + -ing — the doer of -ing is a person other than the main subject.

"I can't imagine George riding a motorbike."
"Did she really say that? I don't remember her saying that."
"Sorry to keep you waiting so long."
"I heard someone shouting outside last night."

📖 GIU Unit 51C, p.102

Verb + -ing — alternative forms Unit 51D-E

having done (완료 형태) / that-clause 대안

D having done — for finished past actions (optional)

having done/stolen/said 형태도 가능하지만, 단순 -ing 형태도 같은 의미 — 둘 다 허용됨.

"They denied having stolen the money." = "They denied stealing the money."
"I now regret saying that." = "I now regret having said that."

E that-clause alternative with deny / suggest / recommend

"They denied (that) they had done anything wrong." (= denied doing)
"Chris suggested (that) we go to the movies." (= suggested going)
"I recommend (that) you take the train." (= recommend taking)

📖 GIU Unit 51D-E, p.102

Verb + to ... (decide to ... / forget to ..., etc.) Unit 52A

to부정사가 뒤따르는 동사 + 부정형 (not to ...) + 일부 동사는 -ing

A After these verbs, use to + infinitive

📖 "After these verbs you can use to ... (infinitive)." (Unit 52A)

offer, plan, manage, deserve, agree, arrange, fail, promise, afford, refuse, hope, threaten, decide, learn, forget, tend
"It was a long way to walk, so we decided to take a taxi home."
"I waved to Emily, but failed to attract her attention."
"I like Dan, but he tends to talk too much."

▸ Negative form — not to

"We decided not to go out because of the weather."

▸ Some verbs take -ing instead (enjoy / suggest / think of) — see Unit 51

"Andy suggested meeting for coffee." (NOT "suggested to meet")

📖 GIU Unit 52A, p.104

Verb + to ... — seem / appear / pretend / claim Unit 52B

seem/appear/pretend/claim + to + (be -ing / have done 형태도 가능)

B seem / appear / pretend / claim + to ...

After seem, appear, pretend, claim, use to + infinitive. Also possible: to be -ing (continuous infinitive) and to have done (perfect infinitive).

"They seem to have plenty of money."
"Anna pretended not to see me when she passed me in the street."

▸ to be -ing (continuous infinitive) — 진행 중

"I pretended to be reading a book." (= I pretended that I was reading)

▸ to have done (perfect infinitive) — 이미 완료된 일

"Have you seen my keys? I seem to have lost them." (= it seems that I have lost them)
"She claimed not to have seen him." (= she claimed that she hadn't seen him)

📖 GIU Unit 52B, p.104

Verb + to ... — dare / question word + to Unit 52C-D

dare + (to) 선택적 / 동사 + 의문사 + to (what/how/where to)

C dare + (to) — "to" is optional

"I didn't dare to tell him." = "I didn't dare tell him."

D verb + question word (what / how / where / whether) + to

ask, know, decide, remember, forget, learn, explain, understand, wonder + what / how / where / whether + to...
"We asked how to get to the train station."
"Have you decided where to go for your vacation?"
"I don't know whether to apply for the job or not."

▸ show / tell / ask / advise / teach + somebody + what/how/where + to

"Can somebody show me how to use this camera?"
"Ask Jack. He'll tell you what to do."

📖 GIU Unit 52C-D, p.104

Verb (+ Object) + to ... — object optional Unit 53A

목적어 선택 동사: want/ask/expect/help/would like + (사람) + to

A want / ask / expect + (Object) + to ... — object changes the infinitive's subject

want, ask, expect, help, would like, would prefer — same verb takes two structures: with or without object

Verb + to ... → to-주어 = 문장 주어

"We expected to be late."
"Would you like to go now?"
"He doesn't want to know."

Verb + Object + to ... → to-주어 = 목적어

"We expected Dan to be late."
"Would you like me to go now?"
"He doesn't want anybody to know."

▸ NOT "want that"

"Do you want me to come with you?" (NOT "want that I come")

▸ help + (to) — "to" optional

"Can you help me move this table?" = "Can you help me to move this table?"

📖 GIU Unit 53A, p.106

Verb + Object + to ... — object required Unit 53B

목적어 필수 동사: tell/advise/remind/warn/etc. + 사람 + to

B verb + somebody + to ... (object required)

tell, advise, remind, warn, invite, encourage, persuade, get, force, teach, allow, enable + somebody + to ...
"It's not a nice hotel. I wouldn't advise you to stay there."
"Joe said the switch was dangerous and warned me not to touch it."
"Who taught you to drive?"

▸ Passive form (be + p.p. + to ...)

"I was warned not to touch the switch." / "Are we allowed to park here?"

▸ Exception: suggest does NOT use this pattern

"Jane suggested that I ask for your advice." (NOT "suggested me to ask")

📖 GIU Unit 53B, p.106

make / let + object + base form Unit 53C

make / let + 사람 + 원형부정사 (to 없이) + 수동은 "made to" 형태

C make / let somebody do something — without "to"

make / let + somebody + do (base form, NO "to")

"I made him promise that he wouldn't tell anybody." (NOT "made him to promise")
"Hot weather makes me feel tired." (= causes me to feel tired)
"Her parents wouldn't let her go out alone." (= wouldn't allow her to go out)
"Let me carry your bag for you."

▸ ⚠️ Passive of "make" uses "made + to"

"We were made to wait for two hours." (= They made us wait...)

📖 GIU Unit 53C, p.106

Verb + -ing or to ... 1 — verb lists Unit 54A

-ing만 쓰는 동사 vs. to만 쓰는 동사 (한눈에 보기)

A Some verbs take only -ing, some take only to ...

Verbs with -ing (NOT to ...)

avoid   imagine   stop
consider   keep (on)   suggest
deny   mind
enjoy   postpone
finish   risk

For examples, see Unit 51.

Verbs with to ...

afford   fail   offer
agree   forget   plan
arrange   hope   promise
decide   learn   refuse
deserve   manage   tend

For examples, see Unit 52.

📖 GIU Unit 54A, p.108

Verb + -ing or to ... 1 — remember Unit 54B

remember + -ing (과거 기억) vs remember + to (미래 할 일)

B remember + -ing vs remember + to

① remember + -ing = memory of the past (이미 한 일을 기억)

② remember + to = don't forget to do (앞으로 할 일을 기억)

📖 "Some verbs can be followed by -ing or to ... with a difference of meaning." (Unit 54B)

▸ remember + -ing (past memory)

"I know I locked the door. I clearly remember locking it." (I did it, and now I remember this.)

▸ remember + to (future task)

"I remembered to lock the door, but I forgot to shut the windows." (I remembered I had to do it, so I did it.)

📖 GIU Unit 54B, p.108

Verb + -ing or to ... 1 — regret Unit 54B

regret + -ing (과거 후회) vs regret + to (격식적인 유감 표현)

B regret + -ing vs regret + to

① regret + -ing = past regret (이미 한 일에 대한 후회: "I wish I hadn't done it.")

② regret + to = formal present (격식적 유감 표현: "I'm sorry to say...")

▸ regret + -ing (past regret)

"I regret telling her the secret." (I told her, and now I wish I hadn't.)

▸ regret + to (formal announcement)

"I regret to inform you that your application was unsuccessful." (Formal: "I'm sorry to tell you...")

📖 GIU Unit 54B, p.108

Verb + -ing or to ... 1 — go on Unit 54B

go on + -ing (계속) vs go on + to (다른 것으로 옮겨가서)

B go on + -ing vs go on + to

① go on + -ing = continue the same thing (하던 일을 계속하다)

② go on + to = move to a new activity (다른 활동으로 넘어가다)

▸ go on + -ing (continue)

"The president went on talking for two hours." (He kept talking — same activity.)

▸ go on + to (next activity)

"After discussing the economy, the president then went on to talk about foreign policy." (Moved on to a new topic.)

📖 GIU Unit 54B, p.108

Verb + -ing or to ... 1 — no difference Unit 54C

begin / start / continue / bother — -ing와 to 둘 다 가능, 의미 차이 없음

C begin / start / continue / bother + -ing or to (no difference)

begin, start, continue, bother + -ing or to ... — meaning is the same
"It started raining." = "It started to rain."
"Don't bother locking the door." = "Don't bother to lock the door."

▸ Exception: don't use -ing after -ing form

"It's starting to rain." (NOT usually "It's starting raining")

📖 GIU Unit 54C, p.108

Verb + -ing or to ... 2 — try Unit 55A

try to do (시도) vs try doing (실험)

A try to do (attempt) vs try doing (experiment)

① try to do = make an effort to do (어려운 일을 시도하다)

② try doing / try something = do as an experiment or test (실험 삼아 해보다)

▸ try + to (attempt — difficult)

"I was very tired. I tried to keep my eyes open, but I couldn't." (Attempted but it was difficult.)

▸ try + -ing (experiment — to see what happens)

"The photocopier doesn't seem to be working. — Try pressing the green button." (Press it to see if it helps.)

▸ Compare

"I tried to move the table, but it was too heavy."
"I didn't like the way the furniture was arranged, so I tried moving the table to the other side."

📖 GIU Unit 55A, p.110

Verb + -ing or to ... 2 — need Unit 55B

need to do (능동) vs needs -ing / needs to be done (수동)

B need to do (active) vs need + -ing / be done (passive)

① I need to do = it is necessary for me to do (능동: 내가 해야 함)

② Something needs to be done / needs -ing = someone needs to do it (수동)

▸ need + to (active)

"He needs to work harder if he wants to make progress."

▸ need + to be done (passive — formal)

"My phone needs to be charged." / "Does your suit need to be cleaned?"

▸ need + -ing (passive — informal, same meaning)

"My phone needs charging." (= needs to be charged) / "Does your suit need cleaning?"

▸ Compare

"I need to charge my phone." (active)
"My phone needs charging." (passive)

📖 GIU Unit 55B, p.110

Verb + -ing or to ... 2 — help / can't help Unit 55C

help + (to) do (to 선택) vs can't help + -ing (자기도 모르게)

C help + (to) base form vs can't help + -ing

① help + (to) do = with or without to (to부정사 또는 원형부정사 모두 가능)

② can't help doing = can't stop yourself from doing it (자기도 모르게 ~하게 되다)

▸ help + base form (without to)

"Everybody helped clean up after the party."

▸ help + to + base form (with to — same meaning)

"Can you help me to move this table?" = "Can you help me move this table?"

▸ can't help + -ing (unable to stop oneself)

"I don't like him, but he has a lot of problems. I can't help feeling sorry for him."

▸ Compare

"Everybody helped (to) clean up." (= they assisted with cleaning)
"She tried to be serious, but she couldn't help laughing." (= she couldn't stop laughing)

📖 GIU Unit 55C, p.110

Verb + -ing or to ... 3 — like / love / hate Unit 56A

like, love, hate 뒤의 -ing와 to부정사 — 의미 차이

📖 GIU Unit 56A, p.112

A like / love / hate — both -ing and to are possible (often no difference)

For repeated actions, use -ing or to ... — usually no difference. 📖 Unit 56A

"Do you like getting up early?" = "Do you like to get up early?"

▸ Existing situation — use -ing only (NOT to)

"Dan lives in Vancouver now. He likes living there." (lives there now and likes it)

▸ I like doing vs. I like to do — sometimes a meaning difference

I like doing = I do it and I enjoy it

"I like cleaning the kitchen." (= I enjoy it)

I like to do = I choose to do it (maybe I don't enjoy it)

"It's not my favorite job, but I like to clean the kitchen as often as possible."

Verb + -ing or to ... 3 — would like / love / hate / prefer Unit 56B

would like / would love / would hate / would prefer — 보통 to부정사

📖 GIU Unit 56B, p.112

B would like / would love / would hate / would prefer + to ...

would like, would love, would hate, would prefer are usually followed by to ... 📖 Unit 56B

"I'd like (= I would like) to go away for a few days."
"Would you prefer to eat now or later?"

▸ Compare I like vs. I would like (I'd like)

"I like playing / to play tennis." (= I like it in general)
"I'd like to play tennis today." (= I want to play today — a specific occasion)

▸ would mind + -ing (not to)

"Would you mind closing the door, please?" (NOT mind to close)

I would like to have done something Unit 56C

would like + to have + p.p. — 과거에 못 한 일에 대한 후회/아쉬움

📖 GIU Unit 56C, p.112

C I would like to have done = I regret now that I didn't / couldn't do it

Form: would like + to have + past participle (p.p.)
Meaning: 지금 와서 보니 그때 그렇게 했어야 했는데 못 한 일에 대한 아쉬움 📖 Unit 56C

"It's too bad we didn't see Anna. I would like to have seen her again."
"We'd like to have gone away, but we were too busy at home."

▸ Same structure after would love / would hate / would prefer

"Poor David! I would hate to have been in his position."
"I'd like to have gone to the party, but it was impossible."

Common Mistakes for Korean Speakers

한국어 화자가 자주 하는 실수

1/2

L1 Interference Warning

Korean does not distinguish between -ing and to after verbs. Memorize which verbs take which form.

"I enjoy to play tennis."
"I enjoy playing tennis." — enjoy is ALWAYS + -ing
"She avoided to speak in public."
"She avoided speaking in public." — avoid is ALWAYS + -ing

Common Mistakes for Korean Speakers

한국어 화자가 자주 하는 실수

2/2

Using -ing with "to" verbs
"I decided going to the party."
"I decided to go to the party." — decide + to + infinitive
Confusing meaning-changing verbs
"Remember buying milk." (intended: don't forget)
"Remember to buy milk."
remember + to = don't forget; remember + -ing = recall a past event

Week 12 Summary

  • Verb + -ing: enjoy, mind, suggest, avoid, finish, consider, deny, risk, give up, keep
  • Verb + to: decide, agree, fail, tend, afford, manage, refuse, promise, learn, hope
  • Verb + object + to: tell/advise/warn/allow sb to... | make/let + bare infinitive
  • remember/forget + -ing = past memory; + to = future task
  • try + -ing = experiment; try + to = attempt | need -ing = need to be done
  • like/love/hate: -ing or to (repeated); -ing only (existing) | would like + to
  • Korean speakers: memorize which verbs take -ing vs. to
