Verb + -ing (enjoy doing / stop doing, etc.) Unit 51

동명사(-ing)가 뒤따르는 동사

A verb + -ing: enjoy doing, stop doing

These verbs are ALWAYS followed by -ing

📖 "After enjoy, mind, and suggest, we use -ing (not to ...)." (Unit 51A)

enjoy, mind, suggest, avoid, finish, practice, consider, imagine, deny, admit, risk, keep, give up
"I enjoy reading." (not "enjoy to read")
"Would you mind closing the door?"
"Chris suggested going to the movies."
"He tried to avoid answering my question."

Verb (+ Object) + to ... Unit 53A-C

동사 + (목적어) + to부정사 — 목적어 선택/필수 + L1 간섭

A want/ask/expect + (object) + to — object optional

want, ask, expect, help, beg, mean (=intend) + (somebody) + to...
"We expected to be late." (no object)
"We expected Dan to be late." (with object)

B tell/advise/remind + object + to — object required

tell, advise, remind, warn, invite, encourage, persuade, get, force, allow + somebody + to...
"I wouldn't advise you to stay there."
"Can you remind me to call Sam tomorrow?"

C "I want you to..." (NOT "I want that you...")

"I want that you help me."
"I want you to help me." — 한국어 "~하기를 원한다" 직역하지 말 것

📖 GIU Unit 53A-C, p.106-107

Verb + Object + base form Unit 53D-E

help (+ to 선택), make / let (+ to 없이) — 원형부정사 사용

D help + (to) base form — "to" optional

help + somebody + (to) do — 둘 다 가능, "to" 생략 더 흔함
"Can you help me find my keys?"
"Can you help me to find my keys?"

E make / let + object + bare infinitive (NO "to")

make / let + somebody + do (base form) — "to" 절대 사용 안 함
"Hot weather makes me feel tired." (NOT "to feel")
"Her parents wouldn't let her go out alone." (NOT "to go")

Verb + -ing or to ... 1 — remember Unit 54A

remember + -ing (과거 기억) vs remember + to (미래 할 일)

A remember + -ing vs remember + to

remember + -ing = memory of the past (이미 한 일을 기억)

remember + to = don't forget to do (앞으로 할 일을 기억)

📖 "Some verbs can be followed by -ing or to ... with a difference of meaning." (Unit 54A)

remember + -ing (past memory)
"I know I locked the door. I clearly remember locking it."
I did it, and now I remember this.
remember + to (future task)
"I remembered to lock the door, but I forgot to shut the windows."
I remembered that I had to do it, so I did it.
"Remember to buy some bananas." = Don't forget to buy them.

📖 GIU Unit 54A, p.108-109

Verb + -ing or to ... 1 — regret Unit 54B

regret + -ing (과거 후회) vs regret + to (격식적인 유감 표현)

B regret + -ing vs regret + to

regret + -ing = past regret

"I wish I hadn't done it."

regret + to = formal present

"I'm sorry to say..."

regret + -ing (past regret)
"I regret telling her the secret."
I told her, and now I wish I hadn't.
regret + to (formal announcement)
"I regret to inform you that your application was unsuccessful."
Formal: "I'm sorry to tell you..." 격식적 표현

📖 GIU Unit 54B, p.108-109

Verb + -ing or to ... 1 — go on Unit 54C

go on + -ing (계속) vs go on + to (다른 것으로 옮겨가서)

C go on + -ing vs go on + to

go on + -ing = continue the same thing

하던 일을 계속하다

go on + to = move to a new activity

다른 활동으로 넘어가다

go on + -ing (continue)
"The president went on talking for two hours."
He kept talking — same activity continued.
go on + to (next activity)
"After discussing the economy, the president then went on to talk about foreign policy."
Moved on to a new topic.

📖 GIU Unit 54C, p.108-109

Verb + -ing or to ... 2 (try, need, help) Unit 55

try / need / help — 의미 또는 형식 차이

A try + -ing (experiment) vs try + to (attempt)

try + -ing = experiment (실험)
"Try pressing the green button."
Do it as an experiment or test.
try + to = attempt difficult (시도)
"I tried to keep my eyes open, but I couldn't."
Attempted but it was hard.

B need + -ing (passive meaning) vs need + to (active)

need + -ing = passive (수동 의미)
"The batteries in this clock need changing." (= need to be changed)
need + to = active (능동)
"I need to change the batteries."

C help + (to) base form — "to" optional

"Everybody helped clean up after the party." = "Everybody helped to clean up after the party." (see also Unit 53D)

📖 GIU Unit 55, p.110-111

Verb + -ing or to ... 3 (like / would like, etc.) Unit 56

like / would like 뒤에 오는 -ing와 to부정사

A like/love/hate + -ing or to (repeated actions — no difference)

"Do you like getting up early?" = "Do you like to get up early?"

B like + -ing — existing situation (already in it)

"Do you like being a student?" (NOT "to be a student")

C like + to... — a sensible habit (good thing to do)

"I like to be at the station early." (= a sensible habit, even if not enjoyed)

D would like/love/hate + to (only)  |  would mind + -ing

"I'd like to go away for a few days."
"Would you mind closing the door?"

📖 GIU Unit 56, p.112-113

Common Mistakes for Korean Speakers

한국어 화자가 자주 하는 실수

1/2

L1 Interference Warning

Korean does not distinguish between -ing and to after verbs. Memorize which verbs take which form.

"I enjoy to play tennis."
"I enjoy playing tennis." — enjoy is ALWAYS + -ing
"She avoided to speak in public."
"She avoided speaking in public." — avoid is ALWAYS + -ing

Common Mistakes for Korean Speakers

한국어 화자가 자주 하는 실수

2/2

Using -ing with "to" verbs
"I decided going to the party."
"I decided to go to the party." — decide + to + infinitive
Confusing meaning-changing verbs
"Remember buying milk." (intended: don't forget)
"Remember to buy milk."
remember + to = don't forget; remember + -ing = recall a past event

Week 12 Summary

  • Verb + -ing: enjoy, mind, suggest, avoid, finish, consider, deny, risk, give up, keep
  • Verb + to: decide, agree, fail, tend, afford, manage, refuse, promise, learn, hope
  • Verb + object + to: tell/advise/warn/allow sb to... | make/let + bare infinitive
  • remember/forget + -ing = past memory; + to = future task
  • try + -ing = experiment; try + to = attempt | need -ing = need to be done
  • like/love/hate: -ing or to (repeated); -ing only (existing) | would like + to
  • Korean speakers: memorize which verbs take -ing vs. to
